# 套图类型

| 类型 | 用途 | 推荐输入 | 文字策略 |
| --- | --- | --- | --- |
| `white_bg` | 商品列表和基础主图 | 正面、侧面参考图 | 无文字 |
| `hero` | 店铺首图和广告氛围图 | 商品图、品牌调性 | 默认留标题空间 |
| `lifestyle` | 展示真实使用场景 | 商品图、目标人群和场景 | 无文字 |
| `feature` | 可视化核心卖点 | 商品图、已核实卖点 | 默认留文案空间 |
| `detail` | 材质、结构和工艺特写 | 高清细节参考图 | 无文字 |
| `size_reference` | 表达产品尺度 | 商品图、准确尺寸 | 未提供尺寸时不生成数字 |

通常先生成 `white_bg,hero,lifestyle,feature,detail` 五张。服饰可把多张参考图分别用于正面、背面和细节；食品应特别检查包装文字、数量和食物形态；电子产品应检查接口、按键、屏幕 UI 和配件；美妆与保健品不得生成未提供的功效或认证。

平台规则与推荐尺寸会变化。计划中的平台字段用于画面意图，不声称替代平台当前规则；正式上架前查看目标平台最新要求。
