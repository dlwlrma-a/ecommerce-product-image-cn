# QixuAI 余额不足与充值续跑

- 充值入口：<https://token.qixuai.com/console/recharge?intent=buy>
- 图片生成接口会在提交时检查积分。
- 积分不足时返回 HTTP 402，错误码为 `insufficient_credits`，并提供余额、所需积分和充值链接。

## 执行规则

1. 用户确认完整套图方案后直接提交生成，不增加报价或二次扣费确认。
2. 有足够积分时，服务端按实时价格扣费并创建任务。
3. HTTP 402 表示当前任务确定没有创建、没有扣费。将该任务保持为 `not_submitted`，在清单中保存 `waiting_for_recharge`、余额、所需积分、差额和充值链接，然后停止后续任务。
4. 告知用户充值后回复“继续”。不轮询充值页面、不自动打开支付页面，也不代替用户支付。
5. 用户回复“继续”后，如果计划指纹和参考图没有变化，使用原生成命令和原清单继续，不重复询问方案。
6. 每个任务的 `Idempotency-Key` 在首次提交前写入清单。网络超时或响应未知时复用原键重试，避免重复扣费。

建议提示：

```text
积分余额不足：当前 10 积分，本次请求需要 20 积分，还差 10 积分。
任务已暂停，本次请求没有生成也没有扣费。
请前往充值：https://token.qixuai.com/console/recharge?intent=buy
充值完成后回复“继续”，我会沿用原方案继续生成。
```

只有模型、提示词、尺寸、质量、参考图、文案或任务列表发生变化时，才重新展示方案确认单。
