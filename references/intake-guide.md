# 电商套图需求访谈

在首次生成前使用本指南。目标是用一次紧凑的对话得到可确认的创意简报，而不是替用户选择或逐题盘问。

## 先判断已知信息

复用用户消息、附件和既有商品档案中已经明确的事实，只询问缺失项。参考图已经提供时先识别可见信息，但不要从图片推断不可见材质、尺寸、功能、认证、配件或功效。

必须确认：

1. 商品名称、品类、具体 SKU/颜色/版本，以及用户当前已有的同款参考图，最多 16 张。先用现有素材规划，不把完整视角覆盖作为开始条件。
2. 目标平台与用途，例如淘宝详情页、京东主图、抖音投流或 Amazon US。
3. 图片文字语言。提供“简体中文 / 繁体中文 / English / 其他”选项，不自行默认。
4. 套图类型与数量。至少从白底主图、氛围首图、场景图、卖点图、细节图、尺寸参照图中选择。
5. 需要出现在图片上的准确商品名、标题、卖点、尺寸和必要免责声明。未知内容不得补写。
6. 比例或尺寸、目标受众、期望场景、视觉风格、品牌色和必须避免的元素。

用户无法提供非关键项时，可以提出一组清楚标记为“待确认”的建议。商品事实、可见文字、尺寸、认证、功效、价格和促销不能作为假设。

## 合并提问模板

只列缺失项，并允许用户直接按编号回答：

```text
生成前需要确认以下信息：
1. 使用平台和用途：淘宝 / 京东 / 拼多多 / 抖音 / 小红书 / Amazon / 独立站？
2. 图片文字语言：简体中文 / 繁体中文 / English / 其他？
3. 套图类型：白底主图 / 氛围首图 / 场景图 / 卖点图 / 细节图 / 尺寸图，需要哪些、共几张？
4. 准确文案：商品名、1-3 条卖点、尺寸或免责声明分别是什么？
5. 受众与场景：卖给谁，希望商品出现在哪里？
6. 画面规格与风格：1:1 / 3:4 / 4:3 / 16:9 / 9:16，以及品牌色、风格和禁用元素？
7. 现有同一 SKU 参考图分别是什么视角？最多 16 张。我会先用这些素材给出可生成方案，再说明补哪些图能提升效果。
```

如果用户说“你推荐”，根据平台、品类、现有素材质量和顾客决策问题提出组合。优先调整构图来适配已知视角，不以补图作为第一答复。

## 套图方案确认单

在调用脚本前先在对话中展示：

```text
商品/SKU：
平台与用途：
目标受众：
目标语言：
比例/尺寸：
视觉方向：
参考图：

现有素材可生成：
| # | 图片类型 | 解决的顾客问题 | 商品状态与场景 | 准确可见文案 | 比例 | 风险点 |
|---|---|---|---|---|---|---|

建议补充素材（可选）：
| 建议视角 | 能提升什么 | 可解锁的镜头 |
|---|---|---|

补图后可生成（不计入本次）：
待确认项：
预计生成张数：
确认后行为：上传本地参考图，并按服务端实时价格直接生成
```

明确告诉用户此时尚未上传或扣费，确认方案后会上传本地参考图并直接发起付费生成。收到“确认这套方案”后创建本地计划并立即进入授权或生成，不再增加报价和二次扣费确认。

## 精确文案

默认根据商品名、已核实卖点和尺寸提出文案供确认。多个同类型镜头应在商品档案的 `shots` 中分别设置 `copy` 和 `direction`；`copy_by_type` 与 `--copy TYPE=TEXT` 仅适合该类型所有镜头共用相同文案的简单套图。例如：

```powershell
--copy "hero=轻盈随行" --copy "hero=全天安心锁温" --copy "feature=单手开合"
```

白底主图不叠加营销文字；需要带标题的主视觉应选择 `hero`。目标语言与原始文案不一致时，只做忠实翻译，并在生成前展示译文供用户确认。
